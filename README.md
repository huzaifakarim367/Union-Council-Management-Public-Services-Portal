# Union Council Management & Public Services Portal

A responsive Union Council website built using HTML, CSS, and JavaScript.

## Features

- Responsive design for PC, MacBook, tablet, and mobile
- Home page
- About Union Council
- Union Council officials
- Public services
- Birth certificate information
- Death certificate information
- Marriage certificate information
- Divorce certificate information
- Online application form
- Notices and announcements
- Development projects
- Contact information
- Responsive navigation menu
- Service information modal
- Mobile-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
